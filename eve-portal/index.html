      EVE Developer Portal 설정

      1. 개발자 포털 → 앱을 등록하고 클라이언트 ID를 붙이세요.

      2. Redirect은 이 페이지 주소를 복사해 그대로 넣고 저장합니다.

      3. 스코프: esi-industry.read characters industry.jobs esi-assets.read characters assets esi-location.read location.type esi-search.structures esi-universe.read structures esi-calendar.calendar esi-wallet.read_corporate_wallet esi-markets.read_corporation_orders

      4. 등록 후 클라이언트 ID 저장 → EVE 로그인
